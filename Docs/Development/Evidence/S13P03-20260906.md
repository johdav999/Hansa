# S13-P03 implementation evidence — 2026-09-06

Implemented the opt-in ElevenLabs SFX and single-speaker English speech adapters. See [workflow and configuration](../ElevenLabsAudioTakes.md).

## Delivered behavior

- External-worker adapters use the fixed SFX and speech models, at most two sequential takes, rights/voice/English acknowledgement, approved voice IDs and explicit spend confirmation. No cloning, multi-speaker or localization batch endpoints are exposed.
- A versioned audio-take profile binds stable SFX/dialogue IDs, speaker identity, subtitle text, duration and silence limits. The generic v1 media contract remains compatible; ElevenLabs requires this additive profile.
- Bounded MP3 downloads retain original hashes and bytes. FFmpeg is checked before spending, decodes without resampling/downmixing, and records its version. Worker and native validation check PCM decoding, sample rate, channels, duration, clipping, silence and profile consistency.
- Native staging prepares non-looping PCM SoundWaves with the appropriate sound group and stable English subtitle text keys. Review opens the native Wave editor and starts playback. Promotion requires the existing exact receipt/hash approval, a playback marker and the matching stable ID; retained originals and final assets remain verifiable without Saved job state.
- Provenance records provider/model/settings, each source/output hash, observed usage and decoder version. Missing usage fails closed. Ambiguous billable submissions are not retried automatically; local cancellation retains known usage and cannot promise to reverse provider charges.
- Shipping scans now include ElevenLabs implementation, configuration and endpoint tokens. No runtime provider dependency was introduced.
