## Final prompt

Create a 1536x1024 reference-only game UI concept for Hansa, an original grounded Hanseatic economic strategy game. Visual system: warm off-white linen work surfaces, restrained aged brass rules and frames, dark ink typography, muted sea-blue selected states, oxblood warning accents, compact information-dense medieval civic ledger tone. Layout: unified slim top status bar; a native desktop city-market workspace below with a market goods list on the left and a selected-good inspector on the right. Add one compact VISITING MERCHANT spot-trade card in the lower selected-good inspector. Component inventory visible in the card: small status heading 'VISITING MERCHANT', eligible berthed cog label, segmented BUY / SELL selector with BUY selected, quantity row with minus button, '5 cargo' readout, plus button, reviewed quote rows 'Est. fill 5 cargo', 'Unit price 1.05', 'Est. total 5.25 marks', report freshness text 'Current report · tick 0', one clear brass-framed primary button 'Confirm purchase', and a reserved one-line result/remedy area. Show an unmistakable keyboard/controller focus ring on the confirm button. Use simple symbolic grain and cog glyphs only. No fantasy ornament, no glossy modern HUD, no neon, no photorealistic props, no extra popups, no tiny unreadable text. This image is a composition reference only; shipping UI is native Slate. Original design, not based on any existing game.
