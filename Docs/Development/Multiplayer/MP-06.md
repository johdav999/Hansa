- Added explicit stable-ID removals for revoked or disappeared collection rows. The controller applies removals before upserts and retains a bounded 256-event assembled cache.
- Full refreshes replace the assembled cache, so a city-interest change cannot leave an old private panel resident.
- Added an authorized-view digest computed from the server's equivalent complete authorized view. The transport/delta digest remains separate; the global simulation hash is diagnostic metadata only.
- Added hard 2,048-entry top-level collection caps and fail-closed projection construction.
- Measured the actual reflected serialized payload and authority build time on every projection.
- World/simulation lifetime remains independent: the acceptance fixture advances authority without a presentation world or streamed actors.

No gameplay definition or save schema changed, so editor metadata, authoring migration, generation schema, and save migration changes are not applicable. The network DTO schema advanced from 1 to 2; old clients fail the existing protocol compatibility gate rather than interpreting the new layout.
