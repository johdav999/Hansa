## Final prompt

The card represents Warehouse in selected state and should feel native to the Hansa city HUD: Linen and Parchment paper surfaces, Baltic Navy structure, Ink labels, Brass selected border/focus accent, subtle Hanseatic Brick ornament, square practical geometry, restrained historic mercantile character. Show a simple warehouse silhouette reference, “Warehouse”, a clear 2×3 footprint, and the prerequisite “Road required.” Keep all changing prices, quantities and key prompts absent so shipping text can be rendered natively. Provide ample localization space and a readable selected state that is not color-only. No glossy card, no fantasy filigree, no unrelated variants, no cropped shadow, no contact sheet.
