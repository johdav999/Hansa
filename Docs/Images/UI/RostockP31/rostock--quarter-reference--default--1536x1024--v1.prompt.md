## Final prompt

Create one Hansa game screen REFERENCE, not shipping bitmap UI, landscape native 1536x1024. A restrained late-medieval Rostock trade quarter facing the Warnow: compact timber quay along the north river bank, broad calm river, inland merchant lanes leading to a modest market square, grouped gabled timber-and-brick residences, a working mill and bakery silhouette, cargo handling beside a dock. An interpreted 120-metre district, not exact historical reconstruction. Camera is a strategy-game elevated oblique view at 55-degree downward pitch, readable 4-metre modular streets and unit-scale buildings. Reuse original Hanseatic architectural conventions, no recognizable copied game assets, no fantasy towers. Keep density bounded (about 16 houses), shared terracotta roof/brick/timber kit, realistic grass/loam bank and gravel lane blending. Crisp sunlight, soft maritime atmosphere, muted Baltic water, readable shadow detail. UI inventory: existing Hansa narrow top HUD shell, city breadcrumb 'Rostock', existing linen city overview drawer, report-age caption 'Recent report', compact action buttons 'Visit city', 'Market', 'Trade map', 'Return to Lübeck'. No construction toolbar in remote city. Existing reusable component language only: Baltic Navy #152A35 and Harbor Slate #29424D flat surfaces, Ink #202628 on Linen #F2E9D8, Brass #C19A52 thin focus border, Source Serif-like headings and Atkinson Hyperlegible-like sans body. Small bounded controls, generous world visibility. Dynamic text in this reference only, will be rendered natively in Slate. Default remote-view state, one visibly focused Return action. No logos, watermark, baked full-screen shipping artwork, glossy UI or decorative filigree. Separate decoration from functional data; show no invented cargo counts or economic numbers.
