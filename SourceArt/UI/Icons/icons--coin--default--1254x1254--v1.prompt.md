## Final prompt

Use case: stylized-concept. Asset type: single production raster icon for Hansa GUI, Coin / total player treasury, also icon-family style anchor. Generate ONE original tiny engraved brass coin with a clear simple embossed merchant balance-scales symbol. Request native 32x32 transparent PNG if possible; if the canvas must be larger, keep the complete icon approximately 64x64 physical pixels at canvas centre, with the rest genuinely transparent, not a checkerboard. Strong readable silhouette designed for 20-32 pixel display, broad clean shapes, restrained engraved character without fine hatching. Three-quarter shallow view, warm Brass #C19A52 highlights, Linen #F2E9D8, dark Ink #202628 contour, subtle Oak #795137 shading. Upper-left light; no cast shadow, no surrounding frame, no text, letters, numbers, logo, watermark or UI mockup. One coin only, isolated alpha background, no montage. Match Hansa's sober Hanseatic counting-house aesthetic. Prefer simple filled shapes over thin strokes. The output will be proportionally resized only if exact native size is unavailable, reviewed at actual size.
