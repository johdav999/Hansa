# Save/load screen reference prompt

- Intended use: composed visual hierarchy reference for the native Slate save/load modal
- Native dimensions: 1536 × 1024 px
- Aspect ratio: 3:2
- Generation mode: built-in ImageGen, new image
- Shipping status: visual reference only; dynamic text, controls, tables, focus, and status are reconstructed in Slate
- Revision: v1, selected compatible manual slot

## Final prompt

ui-mockup. Create an original Hansa game Save and Load screen reference at a native 1536×1024 landscape canvas. Use the established Hansa visual source of truth: deep Hanseatic navy world-overlay shell, warm linen working panels, restrained aged brass separators and selected accents, ink-dark readable text, compact information-dense medieval merchant-ledger character, subtle paper grain, no fantasy ornament. Compose a centered modal over a subdued city backdrop. Header says “Save and load” with a native-looking Close control. Left column is a clear vertical save-slot list with a selected populated Manual save, a populated Autosave, and an Empty slot treatment; each row reserves space for timestamp, scenario, and a status glyph plus text. Right column is a metadata panel for the selected slot: display name, timestamp, Lübeck scenario, save format/build/content compatibility, simulation tick, and compact hash rows. Bottom-right has distinct “Save here” primary and “Load” secondary controls. Show a restrained success/compatibility status banner. Include an overwrite confirmation as a small centered modal layer only as a hierarchy hint. Every interactive control needs a readable focus outline; status must use icon/shape plus text, not color alone. Leave room for localization expansion. Do not bake this mockup into the game; it is a visual reference for native Slate components. No logos copied from other games, no modern glassmorphism, no photoreal objects, no tiny illegible metadata, no decorative excess.

## Inspection

Accepted at original resolution. The screen has a clear two-column hierarchy, readable slot selection, native-control affordances, appropriate navy/linen/brass palette, adequate margins, and no clipped shadows. Generated text is reference-only and is not used in production.
