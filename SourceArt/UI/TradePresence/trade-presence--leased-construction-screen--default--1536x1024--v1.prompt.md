## Final prompt

Create an original 16th-century Hanseatic strategy-game leased-construction screen consistent with Hansa's established GUI. Use deep navy #152A35, warm linen #F2E9D8, restrained brass #C19A52, warm gray stone, compact readable serif headings, and clean sans-serif data text. Show the unified top bar; a central city map with a sharply bounded leased Merchant Quarter using a diagonal hatch and brass boundary; surrounding autonomous city-owned land visibly non-buildable; a right construction browser for Market, Warehouse, and Quay/handling facility with permitted and locked explanations; and a compact legend/status area. Distinguish owned, leased-empty, future-available, prohibited, warning, and invalid land with pattern/shape plus color. Preserve generous safe margins, controller-focus readability, and historical material restraint. No modern neon, fantasy ornament, photoreal HUD, copied game UI, or misleading blanket city ownership. Dynamic labels and values are layout references only and will be native widgets.

## Inspection and revision notes

Selected for clear map/browser hierarchy, bounded hatch treatment, non-color state cues, and compatibility with the approved navy/linen/brass system. Text and controls are reference-only; implementation uses native Slate/UMG. The source is opaque RGB and is not intended for layered production use.
