## Scope and interpretation

This pass profiles the current Lübeck MVP slice and enforces the explicit bounded contracts in
`Docs/TechnicalArchitecture.md`: actor-free authoritative simulation, fixed-step determinism,
bounded histories/projections, scoped replication, a 64 MiB save ceiling, one MiB protocol frames,
disabled-by-default automation, and Shipping exclusion of developer/provider systems.

The architecture does not define hardware-independent millisecond targets for the MVP. Timing
figures below are therefore reproducible local baselines and regression telemetry, not invented
cross-machine release thresholds. The 30–50 city full-campaign target remains outside the MVP.

## Measured defects fixed

1. Population fixtures represented an under-construction residence with 100% progress. State
   canonicalization correctly completed it, invalidating the intended boundary test. The fixture now
   keeps progress and construction state consistent.
2. The same population fixture used a zero-value market good and default five-tick cadence while
   asserting a current one-tick reserve projection. It now uses a valid base value and an explicit
   one-tick cadence; market cadence behavior remains covered by its dedicated test.
3. The integrated Lübeck fixture omitted required footprint dimensions, so the projection registry
   correctly rejected all ten world projections. Every fixture building now has a one-cell footprint.
   The final bakery assertion now distinguishes completed construction from a later supply-blocked
   operational state.
