# Placement action controls prompt

- Intended use: reusable Rotate/Repeat/Confirm/Cancel row and focus-state visual reference
- Native output: 1915×821 pixels
- Generation mode: built-in ImageGen, new generation using the Hansa city-HUD style anchor
- Revision: v1 selected without resampling

## Final prompt

Create one isolated horizontal Hansa build-action control row containing Rotate, Repeat, Confirm and Cancel. Use the established Hansa palette and material language: Linen and Parchment surfaces, Ink text, Baltic Navy framing, Brass focus ring, muted green Confirm and Oxblood Cancel. Show Confirm with an unmistakable keyboard/controller focus treatment and keep every target visually at least 48 pixels high. Repeat should have a selected/toggle indication that is not color-only. Do not bake shortcuts or changing prompts into the controls. Square practical geometry, restrained mercantile ornament, generous spacing, high contrast, no glossy modern dashboard, no fantasy style, no extra variants, no contact sheet.

## Inspection

Inspected at original resolution. Control order, target size, focus visibility, contrast and palette consistency passed. Reference-only.
