## Final prompt

Create a polished 1536x1024 production UI reference for the Hansa historical strategy game, showing the Baltic Trade map with Rostock selected and a completed foreign trade station inspector. Exact visual direction: dark desaturated Baltic-blue full-screen map shell, warm parchment working panels, aged brass frames with restrained verdigris, vermilion used only for warnings, teal for active/prosperity state, crisp native-looking serif headings and highly legible UI typography. Preserve a clear three-column hierarchy: narrow route directory left, generalized Baltic map center with Lübeck and Rostock connected, inspector right. The right inspector heading reads “FOREIGN PRESENCE · STATION INSPECTOR”, state reads “ROSTOCK STATION · ACTIVE”, and shows separate rows for Site, Factor, Lease, Storage 0 / 50 units, Upkeep 25 pfennig / tick, plus a clear “Station is operational” status and a secondary “Close station” control. Top bar remains unified and compact. Include a small tasteful painted harbor vignette as decorative reference only, no photorealism. Do not bake prices, player names, quantities beyond the explicitly requested static reference labels, or keyboard prompts into decorative imagery. Avoid fantasy ornament, modern glass UI, oversized icons, tiny illegible text, contact-sheet layout, and copied game branding. This is a composed screen reference for reconstruction in native Slate, not a shipping texture.
