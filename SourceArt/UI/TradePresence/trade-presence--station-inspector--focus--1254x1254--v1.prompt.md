## Final prompt

Create one isolated reusable UI component reference for the Hansa historical strategy game: a square 1024x1024 foreign trade station inspector panel, shown front-on with generous transparent-safe margins and no surrounding game screen. Visual language: warm parchment interior, slim aged-brass frame with subtle verdigris, dark Baltic-blue title strip, restrained teal active-state accent, vermilion only for warning/error state examples, hand-finished but clean late-medieval mercantile character. Clear hierarchy and exact readable labels: “FOREIGN PRESENCE · STATION INSPECTOR”, “ROSTOCK STATION · ACTIVE”, rows “Site”, “Factor”, “Lease”, “Storage”, “Upkeep”, status “Station is operational”, and action “Close station”. Include small distinct colored icons for site pin, factor person, lease document, storage crate, upkeep coins; status must also use shape/checkmark so it is not color-only. Show keyboard/controller focus as a bright double brass outline around the action. Leave localization expansion space and do not crowd English text. No dynamic prices, names, or gameplay quantities baked into decorative borders. No modern glass UI, no fantasy flourishes, no contact sheet, no mock device, no copied game branding. This is a component style reference for native Slate reconstruction, not a shipping raster control.

## Inspection

Native dimensions verified at 1254 × 1254; no resampling was performed. Labels, distinct icon silhouettes, non-color active cue, action focus outline, margins, palette, and material language are legible. Dynamic values are intentionally blank in the row fields.
