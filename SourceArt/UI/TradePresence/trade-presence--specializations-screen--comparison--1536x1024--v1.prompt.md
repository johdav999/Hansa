## Final prompt

Create a polished 1536×1024 Hansa strategy-game UI reference for a foreign merchant office specialization comparison. Use the established unified top bar and alert language, dark desaturated blue-green background, warm parchment information surfaces, aged brass framing, restrained Hanseatic ornament, high-contrast readable typography, and original colored functional icons. Show one native operational panel with exactly three side-by-side choices: Warehouse, Market, and Harbor. Each card must clearly compare unlocked action, money and goods investment, concrete capacity/order-slot/handling effect, prerequisite, exclusivity, and respec policy. Show Warehouse selected, the other two available, a separate opportunity-cost explanation, and a clearly separated confirmation action. Dynamic values and text are reference-only and will be implemented natively. Include visible default, selected, keyboard/controller focus, disabled/unavailable, warning, and confirmation feedback treatments. No full-screen painted game scene, no baked production text dependency, no modern glassmorphism, no fantasy-gold excess, no copied game branding.
