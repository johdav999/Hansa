# Prompt record — lease overlay legend

- Intended use: reusable visual reference for world-overlay materials, legend chips, and construction permission states; not a shipping atlas.
- Target: 1024 × 1536 (2:3), native generated size; no crop or resampling.
- Generation mode: built-in ImageGen, new image.
- Revision: v1, selected.

## Final prompt

Create a single original vertical component reference for a 16th-century Hanseatic strategy game showing six leased-land overlay and legend treatments: player-owned construction, leased but empty, future available, prohibited city property, warning, and invalid placement. Match Hansa's deep navy #152A35, linen #F2E9D8, brass #C19A52, warm gray, muted teal, ochre, and restrained red. Every state must remain distinguishable without color through unique diagonal hatch, dot field, outline, crosshatch, stripe, or X pattern plus a simple icon silhouette and short reference label. Use restrained brass frames, crisp safe margins, readable small-scale shapes, and flat orthographic UI presentation. Transparent or neutral linen component ground, no scenery, no modern neon, no gradients that obscure patterns, no copied iconography, no baked dynamic values.

## Inspection and revision notes

Selected because all six states have distinct pattern/shape language in addition to color and remain legible as a component guide. The ARGB master preserves alpha capability; final runtime overlays should be native materials/shapes and native text.
