## Verified implementation change

The rendered native UAT initially failed all screen-visibility assertions. The UAT fixture initialized `UHansaScenarioPresentationModel` and immediately called `Close()`, but an unbound briefing is not ready and deliberately cannot be acknowledged. The still-open scenario modal then hid every non-scenario semantic node.

`HansaMvpUiUatTests.cpp` now applies a ready, stable-ID scenario projection before acknowledging the briefing and asserts that the production HUD becomes exposed. The exact rendered test then passed and produced fourteen native bundles: HUD, city market, inspector, route editor, research, scenario, and save/load at 1280×720 and 1920×1080. This changes test setup only; it does not bypass a runtime command or alter player-visible behavior.

- Authoring: use stable definition IDs and the trade-presence city policy/stage/capability schemas described in `TR-02.md`, `TR-05.md`, `TR-08.md`, `TR-10.md`, and `TR-12.md`. Reversed discovery and catalog review remain mandatory.
- Tuning: change authored thresholds, costs, caps, cadence and policies; do not patch runtime state or tests. Re-run trade presence, regional catalog/scale, AI parity and UI projection tests after tuning.
- Migrations: save 21/fingerprint 33 are current. Add an explicit pair, historical encoder layout, migration, idempotent resave check and actionable incompatibility before changing either version. `TR-13.md` records the accepted historical chain.
- Debugging: start with command receipt, domain event, candidate-ledger rollback, inventory/money conservation, station operational state, report age, semantic ID and correlated screenshot metadata. Do not infer authority from a widget.
- UI: preserve widget identity/focus and stable semantic IDs. Rendered tests must bind a ready scenario before dismissing the briefing. Dynamic data remains native Slate/UMG.
- Shipping: run the target exclusion and cooked-content audit, then add the missing final-package/container and launch evidence. Passing a receipt scan does not waive the package gate.
- Future extensions: additional cities may reuse reviewed physical markets/routes, but abstract cities stay visiting-only until a rendered station site and policy are reviewed. Governance remains scenario gated; normal volume never implies annexation.
