# TR-06 — Route integration and station buffering

Status: implemented with focused executable coverage; full ordinary-input rendered journey acceptance remains blocked. This report does not close earlier TR-04/TR-05 or later release gates.

## Contract

The existing command gateway, inventory ledger and vehicle phase remain authoritative. Action values are append-only:

| Value | Action | Effect |
| --- | --- | --- |
| 0 / 1 | Legacy Load / Unload | Existing local transfer / foreign market purchase or sale, unchanged for old routes and saves |
| 2 / 3 | StationLoad / StationUnload | Physical station ↔ Cog transfer, zero price and zero settlement |
| 4 / 5 | OwnedCityLoad / OwnedCityUnload | Physical home-city ↔ Cog transfer; rejected at foreign market-only cities |

No new automatic spot-market transaction is added. TR-03 reviewed visiting trades remain separate; old route commerce is explicitly retained compatibility behavior. An action targets the route owner plus stop city; the presence record resolves the active station's stable ID. Events identify route, ship, city, good, action, tick, quantities and station; ordinary ledger movement records retain source/destination and sequence. Station transfers never publish a RouteTradeSettled event. Factor purchase/sale events and their movement receipts remain separate.

Create/edit validates complete cyclic reachability, vehicle ownership/mode/cargo inventory, known goods, positive bounded quantities, nonnegative reserve, active station ownership and inventory, accepted goods, active presence, and both RouteAccess and LocalStorage capabilities including policy denials. Execution revalidates access, location and station state; changed access produces a missed transfer without losing cargo. Existing finite capacity and reservation checks remain authoritative. Partial/full/missed outcomes use the ordinary route receipt and events. New unload actions protect the specified source reserve and ledger-protected cargo as well.

VehicleMovementAndTransfers precedes MarketClearing. Loading commits physical movement before a factor can sell; factor updates consume only remaining unreserved, unprotected stock. There is no speculative route reservation between ticks. Station loads preserve the maximum live release-order reserve, including paused orders, and the action reserve. Competing transfers/orders cannot consume already committed goods. Factor purchases accumulate over market updates; the Cog loads those actual units and sails independently. Conversely it unloads to the station and departs while bounded factor sales continue.

The home-city action deliberately uses the existing shared home inventory contract; it does not introduce private ownership of foreign city market stock. No new construction rights, buildings, capability definitions, catalog promotion, provider calls, or TR-07 contributions are introduced.
