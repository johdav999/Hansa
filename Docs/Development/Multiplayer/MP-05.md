## Implementation

- Advanced the client intent schema to version 2 while preserving the original three enum values for compatibility.
- Added bounded DTOs for atomic placement batches and route stops/actions. A held road stroke is one server transaction; it never spends one segment at a time.
- Added authority-aware runtime entry points for construction cancellation/demolition, residence and production changes, heating and household policy, route create/edit/cancel, and ship movement. They derive the issuing house and principal from the admitted server session rather than client payloads.
- Kept route and building identity server-owned. Route creation allocates the route ID on the server; clients submit only the vehicle, name, policy, and bounded plan.
- Added validation for stable-ID lengths, positive IDs and quantities, coordinates, rotations, route names, 2–16 stops, up to 16 actions per stop, at most 256 placements, reserve limits, heating days, and current schema.
- Added an optional expected-server-tick precondition. Future selections and projections more than 64 ticks old are rejected before sequence consumption with an actionable refresh remedy.
- Kept strict per-client monotonic sequences and nonce replay checks. Accepted replays, skipped/reordered commands, and cross-owner targets are rejected before mutation. Successful commands receive a single authority-assigned global order.
- Added explicit `Pending`, `Accepted`, and `Rejected` feedback states. Local submission immediately publishes pending feedback; the reliable server response carries cause, remedy, gateway error, sequence, nonce, and server tick.
- Routed build-menu construction/demolition, inspector production/residence/heating/household/ship actions, trade-map create/edit/start/pause/cancel, manual world ship orders, and research through the controller's single semantic submission entry point in network mode.
- Preserved local previews. Placement preview and route review may inspect local presentation data but cannot spend resources; only an accepted server intent mutates authoritative state.
- Preserved standalone branches and the existing typed local gateway.
